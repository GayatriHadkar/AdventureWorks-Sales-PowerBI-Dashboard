
# AdventureWorks Sales Analysis Dashboard

An interactive Power BI project exploring AdventureWorks sales data from 2020 to 2022.

## Project Overview

This project uses Microsoft Power BI to explore sales performance, products, customers, and geographic trends through an interactive report.

## Objectives

- Explore sales performance across multiple years.
- Analyze products and product categories.
- Examine customer-related trends.
- Visualize geographic sales distribution.
- Build interactive reports for business analysis.

## Tools and Technologies

- Power BI Desktop
- Power Query
- DAX
- Microsoft Excel

## Dataset

The repository includes sales workbooks for 2020, 2021, and 2022, along with supporting lookup files for customers, products, categories, subcategories, dates, territories, and returns.

## Repository Structure

- `Dashboard/` — Power BI report
- `Dataset/Raw_Data/` — Source Excel workbooks
- `Screenshots/` — Dashboard previews
- `Documentation/` — Project explanation and notes

## Data Preparation

The source data is prepared and modeled in Power BI. Power Query supports data preparation, while DAX measures and report visuals support analysis.

## Key Insights

- The dashboard provides an interactive view of sales performance across 2020–2022.
- Sales can be analyzed across different product categories, customers, territories, and time periods.
- The Map page provides a geographic view of sales distribution across territories.
- The Product Detail and Customer Detail pages enable more focused analysis of individual products and customers.
- The Decomposition Tree and Key Influencers visuals provide additional ways to explore factors affecting sales performance.
- Interactive filters and report-level navigation allow users to explore the data from different perspectives.

## How to Use

1. Clone or download this repository.
2. Open the `.pbix` file using Power BI Desktop.
3. If necessary, update the source paths to match your local dataset folder.
4. Refresh the data and explore the report pages.
